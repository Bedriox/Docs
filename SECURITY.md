# Security Policy

Do not publish suspected vulnerabilities in a public issue.

While the repositories are private, report a vulnerability directly to the
Veno Ninja LLC repository administrators with:

- affected repository, revision, and platform;
- reproduction steps or a minimal packet/input fixture;
- observed and expected behavior;
- likely impact; and
- whether the report contains sensitive data.

Before public release, Veno Ninja LLC will publish a dedicated private-reporting
channel and supported-version table. Until then, no response-time or bug-bounty
commitment is offered.

Remove account tokens, JWT chains, IP addresses, device identifiers, and player
data from reports unless they are essential; if essential, coordinate a secure
transfer first.
