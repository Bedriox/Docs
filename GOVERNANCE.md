# Governance

Bedriox is stewarded by Veno Ninja LLC. Maintainers appointed by Veno Ninja LLC
may review changes, manage releases, and enforce project policies.

Routine documentation changes are accepted through reviewed pull requests.
Changes affecting public contracts, compatibility promises, security posture,
repository boundaries, or licensing require an RFC before documentation is
updated. Maintainers record decisions and material dissent in the relevant RFC.

No contributor obtains authority to bind Veno Ninja LLC merely by
participating. Trademarks and release signing remain under Veno Ninja LLC's
control.
